# 阶段 1B：项目隔离与稳定身份验收约定

基座：R1 c1e1364（0.7.4）。来源：规划3/00、11 §1B；用户已确认K1/K2优先。
不搬会话文件、不迁移索引结构。所有开发测试使用TEMP合成环境。

## 作用域

- 项目会话只读本项目及allow_child允许的子项目；read_standalone默认false，只取发起项目的值。
- 开启后只扩大主动search、手动resume，不把非项目会话加入启动包接续推荐（K1）。
- 非项目/无法反查会话只读公共池和非项目池；删除项目遗留会话仍保留自己的项目作用域。
- 公共池、全局提示词始终可读。通用经验与Dream不在本阶段实施。
- 不给index.sessions加全局过滤，不破坏来源解析；只在各读取入口求作用域。
- 新会话显式指定不存在项目则拒绝；老会话重新归属时同步刷新旧、新索引Markdown。

## 检索、续接、附件

- 至少20个不同查询词验证项目A不返回项目B；默认不返回非项目会话；不继承父子开关。
- limit=5：项目保底3、公共保底1；剩余额依次项目、公共、独立，独立最多1。
  对应例：项目>=5/公共>=2/独立>=2得到4/1/0；2/0/3得到2/0/1；2/3/3得到2/3/0。
- 非项目调用保持公共池→独立池顺序；排除当前会话；limit小于5不超数、不越界。
- 手动resume校验目标头字段归属；重名先筛可见候选，再明确报歧义，不取任意第一个。
- fork覆盖头字段与目录背离的情况；非项目启动包不注入带项目归属的附件。
- 读取端不调用校时。索引错误的记录只写临时app_home的文件，不污染协议stdout。

## 项目卡、身份与入口

- read_standalone为可选布尔，旧卡读取false，不写回；窄setter只改明确传入的开关。
- 新项目生成p-加12位小写十六进制project_id；编辑、改名保留；旧卡读取None，不回填。
- 改项目名时按会话头字段找全部关联会话，并改附件中的旧项目名；不按目录漏找。
- 新增project set；未传开关不改。桌面开关使用独立API，不回写旧表单的其他字段。
- 拒绝精确保留名__standalone__；拒绝前不修改旧卡或会话，不扩大大小写规则。
- project ids预览不写Vault；apply先备份，只插入project_id一行，其他字节不变。
- 旧ID优先从地图等已有产物头恢复；找不到才分配。不给全部会话头批量加ID。
- 真实Vault回填仍待用户看过具体预览后批准。本阶段只实现并在TEMP验证写入口。

## 回归与说明

- Codex/pi同一合成Vault的项目段、search及resume行为一致，不需要模型、凭据或真实宿主。
- 旧卡字节在读取、未传开关时不变；回退R1读取和编辑仍保留未知键。
- 原版0.7.3可读新卡，但编辑会丢新增字段，必须在升级说明写清楚。
- 用pathlib只读统计非项目池总数、90天内数量、头与目录背离数量；仅聚合输出，前后哈希核对。
- 每个修改补直接相关用例；阶段末全量无新增失败，git diff --check通过。
- 公共池待确认改索引（K2）在1C统一实施，1B不另建pending机制。
