# 记忆闭环基线口径

来源：规划3/10 §0.9。只读真实Vault，确定性调用仅在TEMP副本执行。
基线源码从 v0.7.3 解包到TEMP，不依赖正在修改的开发源码。
真实目录只输出聚合数字，不输出项目名、会话名或正文；不读取宿主凭据。

- M1：每项目最新会话为相同续接输入，按Codex/pi预算生成；统计四节完整率。
  没有会话的项目用空续接输入，单列计数。四节内容来源和模式保持一致。
  用户U9确认保留来源待核对标记，产品验收采用有效业务内容正确展示；原始逐字指标继续独立报告。
  阶段末原始32/36不改写；已验证的有效规则78/78、其余三节各36/36满足本轮产品验收。
- M2：固定查询词为“项目、问题、测试、记忆、配置、安装、继续、修复”。
  每项目、每宿主运行同组查询；允许allow_child包含的子项目。
  统计其他非空项目命中、非项目命中及命中总数，避免用无命中冒充隔离成功。
- M3：逐条比对项目硬规则、启动包中规则、明确标注来源待核对的规则。
  只统计没有注入且没有标注的规则。项目内规则本身超预算时另列。
- M4：只在副本逐张模拟取代缺指纹卡，统计受阻次数和原因类别。
  不把副本内的写入应用到真实Vault。下降目标在看到基线后再确定。
- M5：新会话首条用户指令与项目上次会话目标的字符二元组集合Jaccard重合度。
  阈值0.5只作启发式趋势描述，并同时报告0.3、0.7敏感性，不作通过线。
- M6：固定纠正短语为“不是这个、理解错了、我说的是、你搞错、不是这样、我不是这个意思”。
  统计含任一短语的用户指令数除以会话数，只描述趋势，不作通过线。

真实Vault哈希范围按总览§5.2。若只在会话总结/.tbrain发生窗口内变动，
记为疑似活跃会话写入并重测一次；其他目录变化则停止并报告。
报告不声称从字面相似度或短语匹配证明模型重复解释、理解错误的真实原因。
