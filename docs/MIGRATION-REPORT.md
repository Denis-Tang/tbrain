## 6. 风险与回滚

- **同名冲突**：不同项目下同名会话/同名公共池卡片；迁移时按项目目录隔离，公共池同名合并为“最新生效 + history”。
- **字段丢失**：旧 progress/next_actions 为自由文本，拆条可能不完美，原文一律保存在新总结的 `待整理` 节。
- **回滚**：新 vault 迁移前备份；失败则恢复备份并删除本次新建文件；旧数据始终只读，不受影响。
- **重复执行**：迁移按“来源文件 + 内容哈希”幂等，重复运行只补缺失/更新变化，不重复插入。
